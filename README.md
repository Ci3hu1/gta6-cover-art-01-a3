Afterglow Vice Cover Studio — a self-contained browser studio that builds GTA VI magazine covers. Pick a frame, a colour story and a headline, and export the cover as a PNG. No network, no build step, pure stdlib.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The grader entrypoint is `node main.ts` (copies `app/` and `screenshots/` to `$MAKEFUN_OUTPUT_DIR` and writes `dossier.json`).
